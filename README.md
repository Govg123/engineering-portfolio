# Wyatt Catz Engineering Portfolio — media version

This version uses your real project photos and videos.

## Preview locally
Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

## Publish quickly
### Netlify
1. Go to Netlify and sign in.
2. Drag the entire `wyatt_portfolio_v2` folder into the deploy area.
3. Netlify will give you a public URL.

### GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Go to Settings → Pages → Deploy from branch → `main`.

## Important before submitting
- Review every caption and make sure it reflects your personal contribution accurately.
- Add your resume PDF if you want a Resume button.
- If any team image shows work you did not personally perform, keep the caption framed as team/project context (the current copy does this).

## Editing
- Text: edit `index.html`.
- Styling: edit `styles.css`.
- Images/videos: replace files inside `assets/` and keep the same filenames, or update the file paths in `index.html`.
